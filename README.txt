
SETUP

1. Upload ALL files to GitHub repo.
2. Open Telegram bot and press START.
3. GitHub Repo -> Settings -> Secrets and variables -> Actions.
4. Add:
   TELEGRAM_TOKEN
   CHAT_ID

5. Go to Actions tab.
6. Run workflow manually once.
7. Check Telegram.

COMMANDS:
/ping
/status
/watchlist
/help

The bot runs every 15 minutes automatically.
